# SSF 2023 Frontend

선린인터넷고등학교 소프트웨어 나눔축제 2023 웹사이트

## 기술 스택

- React 18 + TypeScript
- Vite (빌드 도구)
- Emotion (스타일링)
- React Router (라우팅)

## 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 배포
npm run deploy
```
